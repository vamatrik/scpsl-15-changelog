Gameplay

  • Slightly altered and slightly increased the size of hitboxes on all human classes.
  • Sneak speed for all human classes increased to 2.3 m/s (from 1.6).
  • Improved human "landing" animations.
  • This is the animation that plays after a human jumps, then touches the ground.
  • Scientists now only spawn in LCZ Checkpoints.
  • One Facility Guard spawn is replaced with a Scientist spawn in the default spawn queue.
  • This replaces the third player spawned in the round (that is currently spawned as a Guard) with a Scientist spawn.
  • Chaos Insurgents now share the same footsteps audio range as NTF.
  • Mini-wave spawn counts are now equal to 25% of the server’s population (from 20%).
  • This means an additional player should spawn in each mini wave on 25 player servers.
  • The winner of the round is now purely decided based on the last team standing.
  • Civilian escapes no longer have an affect on win conditions
  • Stalemates still exist as a failsafe.
  • "Forget About Your Fears" is now louder and starts playing almost immediately when a human is the last one alive.
  • Greatly improved performance of breaking glass particles.
  • Slightly expanded the framework for facial expressions.
  • Humans will change facial expressions when being grappled or having their eyes severed.
  • Ragdolls will retain the previous facial expression of the player, slowly transitioning to a random death pose.
  • Dying from SCP-173 or bleeding from severed eyes uses a custom expression.

All SCPs

  • SCP hit animations will now play even if it doesn't deal any damage.
  • This is specifically noticeable on SCP-939.
  • SCP-106, SCP-173, and SCP-939 now have a new standard SCP head height of 1.95 meters.
  • For reference, human head height is 1.8 meters and flamingo height is 1.2 meters.
  • Dead Man Switch percentage health regen is now based on how many main spawn waves have spawned. Each wave spawned increases the percentage healed by 7.5%:
  • Zero waves spawned results in a 0% heal.
  • One wave spawned results in a 7.5% heal.
  • Note: The above two should never happen naturally, but exist as a failsafe.
  • Two waves spawned results in a 15% heal.
  • Three waves spawned results in a 22.5% heal.
  • Four waves spawned results in a 30% heal.
  • The flat 250 HP heal is unaffected.
  • Dead Man Switch activation countdown is now paused while the Alpha Warhead is actively detonating.
  • Added a teammate outline to all SCPs within ~75 meter radius.
  • The radius should be enough to see each other on opposite sides of a zone.
  • This doesn't apply to SCP-079, who doesn't see its teammate's outlines.
  • One minute after the Alpha Warhead's detonation, all living humans will become outlined red, and through the walls to the entire SCP team within a ~90 meters radius.
  • This lasts until the end of the round.
  • SCP Abilities (and their keybinds) are now displayed on their HUDs.
  • Read more below, under "UI Changes".

SCP-953

  • Added a new playable anomaly: SCP-953.
  • SCP-953 specializes in deception and disruption. By utilising her abilities, she can integrate into groups, switch forms to adapt to new situations, and then unleash her powerful offensive abilities when revealed.
  • SCP-953’s abilities rely on Essence: a resource that is generated while being near, or taking damage from humans.
  • Upon reaching 50% Essence, SCP-953 can reveal itself.
  • SCP-953 begins the round in a disguised state amongst human classes.
  • It cannot regenerate Essence for the first 90 seconds of the game, meaning it is unable to reveal itself for that time.
  • SCP-953 is given access to a disguise menu, where it can select between multiple forms or reveal itself.
  • Upon reaching sufficient Essence, SCP-953 can use the Bewitch ability to violently reveal itself and inflict nearby humans with Hexed.
  • Hexed is a new status effect that disorients its victims and makes them more vulnerable to SCP-953’s attacks.
  • When revealed, SCP-953 gains access to its offensive abilities.
  • It can rapidly slash at nearby humans to regain Essence.
  • SCP-953 can transition into a quadrupedal state that gives it enhanced mobility and an alternate attack: Pounce.
  • Pounce must be charged and deals severe damage alongside rewarding SCP-953 with shield upon a successful hit.
  • Hitting Hexed targets with Pounce will Grapple them, allowing you to drag them around and then execute them.

Developer Commentary: SCP-953 has finally arrived in a playable form. She will be iterated on throughout the beta with her art and audio passes being completed as time goes on. Please let us know what you think of her, as your feedback will be essential in making any adjustments!

Firearm Clutter

  • Firearms will now drop additional visual clutter during gameplay:
  • Repeaters with detachable magazines now drop them during combat reload.
  • Revolver drops the speedloader during any reload animation which involves using it.
  • Pumping the Shotgun ejects the empty shells.
  • Disruptor ejects the battery during reload. If the reload is interrupted by dropping/holstering it, it won't drop another battery until it is fired again.
  • This is a small visual detail, not intended to affect balance, so it contains several limitations for the sake of keeping things optimized:
  • Similar to bullet holes and blood decals, storage is handled client-side. As a result:
  • Physics is not synchronized between players. That means clutter can bounce in random directions and end up landing in slightly different locations for different players.
  • Joining the server mid-round won't cause the previously dropped clutter to appear.
  • There is a soft limit of 25 instances, shared by all kinds of dropped clutter. If the number of instances exceeds that limit, the oldest instance begins to decay (fade away into transparency over the course of a few seconds).
  • The same decay happens to instances that have existed for longer than two minutes, even if the soft limit has not been reached.

Usable Phones

  • Phones spawn in a lot of locations, including all containment chambers and rooms with special points of interest (warhead, labs, etc.).
  • All roles can make calls by interacting with a phone. When that happens, all phones in the facility will ring at once.
  • When someone answers the phone, they can talk to each other by simply transmitting on proximity voice. SCPs that don't have proximity voice chat can still listen, but can't transmit.
  • When someone misses the phone, the phone stops ringing, but they can still join the call by interacting with the phone again.
  • As with radios and intercom, only voice data is transmitted. Environmental sounds are not recorded.
  • When the last person in proximity to the phone interacts with it or walks away, the phone will automatically disconnect.
  • The display on the model lists all connected phones.
  • SCP-939 interactions:
  • Recorded player voices can be transmitted through the phone.
  • This does not affect other mimicry, such as gunshots or footsteps.
  • SCP-079 interactions:
  • If the camera is in range of the phone, voice will automatically be picked up by phones without needing to interact. The same applies to hearing players.
  • If the camera is farther away, interacting with the phone will allow SCP-079 to transmit and hear voice regardless of distance.
  • Otherwise, pressing the icon is the same as pressing the interact button, like a regular player.

Outlines

  • Added a system to the game that lets you see an outline of specific players or objects locally and sent from the server to clients.
  • Allows to change Priority, Colour, Thickness, StencilShrink (how sharp the edges should be, with 0 being general object outline), SeeThroughWalls & Fill.
  • This system uses a custom shader with a custom draw pass to render the top most priority outline for every OutlineEffectController (if it has any active).
  • Every controller has its own material that lasts for the controller's lifetime, reusing it until the end. All outlines that are considered fully transparent are also not rendered, saving draw calls.
  • Outlines are objects whose instances belong to single controller. There is a copy constructor, which creates deep copy and increments the ID to a new one, and a clone Clone() method if you create a template, such as one created via Unity serialisation, and then distribute it to all players.
  • Current system allows creating outlines visible to everyone/specific role(s)/specific team with the exception of role(s).
  • Outlines also prevent some of the culling of the outline objects, both on the server and client side, to make sure they are visible when they should be through walls.
  • Outlines on themself cannot be edited in real-time by re-sending data. But there are several modifiers which let you handle these on the client side or send sync values to the client. The current available modifiers are:
  • DistanceBasedModifier for close and distance fade in and out.
  • CurveBasedOutlineModifier to change properties over network time via curves.
  • NetworkedCurveModifier to change the properties via synced float value for evaluation.
  • PlayerStatOutlineModifier to change properties via automatically synced normalised float value of player's StatBase.
  • SCP-1507's teammate visibility through walls now utilizes the outlines system instead of its own.
  • Added outline add and outline remove console commands.
  • Added Selection-based outline, which allows outline to be visible for specific player(s) only.
