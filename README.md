# SCP: SL 15.0 — Changelog Terminal

Интерактивный двуязычный (RU/EN) просмотрщик публичного чейнджлога **SCP: Secret Laboratory v15.0.0 Beta** в стиле карты SCP-079.

- Карта комплекса (Поверхность / Офисная / Тяжёлая / Лёгкая зона): клик по комнате открывает досье с изменениями
- Мышь — карта плавно следит за курсором; drag — двигать; колёсико/щипок — масштаб
- `Tab` каталог · `F` или `/` поиск · `1–4` зоны · `Пробел` общий вид · `M` слежение мышью · `Esc` закрыть
- Прогресс чтения = EXP и уровни доступа 079; AP тратится на открытие дверей (шутка, читать можно всегда)
- Ссылки на разделы: `#/armory/shotgun`

Сайт статический (HTML/CSS/JS, без сборки) — просто залейте корень репозитория на GitHub Pages.

## Обновить текст
Исходник чейнджлога — `_src/changelog.txt`, переводы — `_build/ru/*.txt` (`номер|текст`).
После правок: `cd _build && python3 parse.py && python3 build_data.py` → пересоберёт `js/data.js`.
Разделы, комнаты на карте и шутки — `js/config.js`.

Неофициальный фанатский проект. Текст изменений © Northwood Studios (публичный документ), перевод — фанатский.

## Карта
Раскладка комплекса — реальный пример генерации 14.2.7 (`_build/layout_src_14.2.7.json`, из проекта ScpWorldMap), собирается в `js/layout.js` командой `node _build/build_layout.js`.
Плитки комнат — иконки карты 079 из 14.2.7, перерисованные в «чертёжный» стиль: `python3 _build/tint_rooms.py <папка_с_иконками> img/rooms`.
